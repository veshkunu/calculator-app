# Responsive Calculator App

A modern responsive calculator web application built using **HTML**, **CSS**, and **JavaScript**.
This project was developed as part of my frontend learning journey to understand DOM manipulation, event handling, responsive design, and JavaScript logic implementation.

---

## Features

* Basic arithmetic operations

  * Addition (`+`)
  * Subtraction (`-`)
  * Multiplication (`*`)
  * Division (`/`)

* Responsive design using Media Queries

* Keyboard support

* Real-time display updates

* Delete (`DE`) functionality

* Clear (`AC`) functionality

* Error handling for invalid expressions

* Modern neumorphic UI design

* Interactive hover and active button effects

* Grid background aesthetic

---

## Keyboard Shortcuts

| Key       | Function              |
| --------- | --------------------- |
| 0-9       | Numbers               |
| + - * /   | Operators             |
| Enter     | Calculate result      |
| Backspace | Delete last character |
| Delete    | Clear display         |

## Responsive Design

The calculator is fully responsive and adapts to:

* Desktop screens
* Tablets
* Mobile devices

Implemented using:

* Relative sizing
* `max-width`
* Media Queries
